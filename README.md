# DemoBlaze E-Commerce Test Automation


Automated testing framework for DemoBlaze e-commerce website using modern testing tools and practices.

## 🛠 Tools Stack
- **UI Automation**: Selenium WebDriver (Java)
- **API Testing**: Postman
- **Performance Testing**: JMeter
- **CI/CD**: Jenkins
- **Version Control**: GitHub
- **Build Tool**: Maven


## 📦 Prerequisites
- Java JDK 11+
- Maven 3.9.9
- Chrome browser
- Jenkins (for CI)
- JMeter 5.6.2 (for performance tests)
- Postman (For API)
